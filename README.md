# Source Eleventy Port

Eleventy `3.1.5` port of the original Ghost Source theme.

## Credit

- Original theme: `TryGhost/Source`
- This repository is an Eleventy/Handlebars port.

## Stack

- Eleventy `3.1.5`
- Handlebars + Nunjucks
- Luxon date formatting

## Global Data

- `_data/metadata.json`

## Commands

```bash
npm install
npm run start
npm run build
```

## Routes

- `/`
- `/posts/:slug/`
- `/tags/`
- `/feed/feed.xml`
- `/sitemap.xml`
- `/robots.txt`
- `/humans.txt`
